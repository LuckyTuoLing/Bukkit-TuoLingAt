1.0 1.8 ~ 26.x Spigot / Paper

安装与前置

环境要求

项目要求
服务端Spigot / Paper 及其分支，1.8 ~ 26.x
JavaJava 8 及以上（与服务端版本要求一致即可）
硬依赖无
软依赖PlaceholderAPI（可选，缺失不影响任何功能）

安装步骤

放入插件 将 TuoLingAt-1.0.jar 复制到服务端 plugins/ 目录。
完全重启服务器 首次启动会生成 plugins/TuoLingAt/config.yml，并在控制台打印插件横幅（含支持版本与当前服务端版本）。
验证 游戏内执行 /at 查看帮助；控制台会输出插件已启动的提示。
替换 jar 后请整服重启
用 /reload 或插件管理工具热重载时，已经加载过的类可能不会被替换，导致仍在跑旧代码。 排查问题时，先看一眼出错日志里的行号是否和当前源码对得上。

配置文件

路径：plugins/TuoLingAt/config.yml。改完执行 /at reload 生效。

yaml 
Message:
  Sender:                              # 发起者自己看到的提示
    AtOther: "&f[&6系统&f] 你艾特了: &e%target%"
    InCooldown: "&f[&6系统&f] 艾特的太快了!先等到 &e%cooldown% 秒后再艾特吧"
    AtWrong: "&f[&e系统&f] &c玩家不存在或者不在线."
    CannotAtSelf: "&f[&e系统&f] &c你不能艾特自己."
    Sound: "ENTITY_CAT_AMBIENT,1,1"
  target:                              # 被艾特者收到的提示
    Title: "&6%sender%,&b好像在艾特你,10,30,10"
    ChatBot: "&f[&e系统&f] 玩家 &b%sender% &f在艾特你,快去回复他吧."
    Sound: "ENTITY_CAT_AMBIENT,1,1"
Setting:
  CommandCooldown: 10                  # 冷却秒数（指令艾特与聊天框普通艾特共用）
  OpNoCooldown: true                   # OP 是否无视冷却
  EnableChatAt: true                   # 是否启用聊天框艾特

Message.Sender · 发起者提示

键作用可用占位符
AtOther艾特成功时给自己的反馈（艾特全员时不发，避免刷屏）%target%
InCooldown处于冷却中时的提示%cooldown%
AtWrong目标不存在或不在线时的提示—
CannotAtSelf尝试艾特自己时的提示—
Sound给自己播放的音效—

Message.target · 被艾特者提示

键作用可用占位符
Title弹给对方的屏幕标题%sender%
ChatBot发给对方的聊天提示%sender%
Sound给对方播放的音效—

Setting · 行为开关

键默认说明
CommandCooldown 10 冷却秒数，0 或负数表示不限制。指令艾特与聊天框普通艾特共用同一条冷却。
OpNoCooldown true 开启后 OP 无视冷却（也不会占用冷却）。设为 false 则 OP 同样受限。
EnableChatAt true 是否启用聊天框艾特。关闭时插件不会注册聊天监听，/at reload 后可即时切换。
颜色写法
文案里用 & 加颜色代码，例如 &f 白、&e 黄、&c 红、 &6 金、&a 绿、&b 青、&l 加粗。 插件会自动转换成游戏内颜色。

消息占位符

配置文案里可以写下面这些占位符，发送时会自动替换：

占位符含义出现在
%target% 被艾特的玩家名 Message.Sender.AtOther
%sender% 发起艾特的人；由控制台发起时为 Console Message.target.Title / ChatBot
%cooldown% 冷却剩余秒数 Message.Sender.InCooldown

命令与权限

命令说明权限节点冷却
/at <玩家名> 艾特指定在线玩家 无需 受冷却
/at all 艾特所有在线玩家（不含自己） tuolingat.atall 受冷却
/at random 随机艾特一位在线玩家（不含自己） tuolingat.atrandom 受冷却
/at reload 重载配置并同步聊天监听开关 tuolingat.reload —
/at · /at help 显示帮助 无需 —

补充说明

  • 命令别名 /hanat 与 /at 完全等价。
  • 控制台可用：控制台执行 /at Steve 时，对方看到的 %sender% 是 Console，且不受冷却限制。
  • 权限判定走 hasPermission，控制台天然拥有全部权限；用 LuckPerms 之类的权限插件给玩家组授权即可。
  • /at random 与 /at all 在没有其他人在线时，会提示"服务器无其他人在线"。

Tab 补全

输入 /at 后按 Tab 会补全当前在线的玩家名（按名字匹配，不区分大小写）。

聊天框艾特

开启 Setting.EnableChatAt（默认开启）后，玩家在聊天框里直接打艾特就能触发， 不需要记命令。

输入行为对照

输入显示颜色行为
@Steve 绿色 艾特 Steve，对方收到聊天提示 + 标题 + 音效
@ Steve（带空格） 绿色 同上，且消息里的空格会被去掉，显示为 @Steve
@all · @全体玩家 黄色 艾特除自己外的所有在线玩家，需要 tuolingat.atall；发起者不会收到逐条的"你艾特了谁"提示
@random · @随机玩家 黄色 随机艾特一位在线玩家；消息里会直接显示抽到的玩家名，需要 tuolingat.atrandom
@自己 不变色 提示"你不能艾特自己"
@不存在的人 不变色 提示"玩家不存在或者不在线"（一条消息只提示一次）

冷却规则

入口是否受冷却
指令 /at <玩家名>受冷却
指令 /at all · /at random受冷却
聊天框 @玩家名受冷却
聊天框 @all · @全体玩家 · @random · @随机玩家不受、也不占用冷却
OP（OpNoCooldown: true）无条件放行
一条消息只扣一次冷却
消息里写了多个 @玩家名 时，只在触发前检查一次冷却，不会因为艾特的人多而重复扣。 冷却中的提示只发给发起者，不会打扰被艾特的人。

其他细节

  • 大小写不敏感：@steve 可以命中在线玩家 Steve。
  • 重复去重：@Steve @Steve 只艾特一次；@Steve @all 时 Steve 也不会收到两遍。
  • 关键字优先：若服务器真有玩家叫 all / random，这两个名字会优先按关键字处理；全体玩家 / 随机玩家 是中文别名，只整体匹配，不会吃掉跟在后面的中文。
  • 权限与指令一致：聊天框的 @all / @random 同样校验权限，无法绕过指令限制。
  • 热开关：把 EnableChatAt 改成 false 后执行 /at reload，插件会直接注销聊天监听（不注册即不产生开销）。

音效与标题格式

音效 · Sound

格式：音效名,音量,音调，后两项省略时默认为 1.0。

参数含义取值范围
音效名播放哪个音效见下方两种格式
音量越大越响，也影响可听距离0.0 ~ 1.0 常用，可更大
音调越高越尖0.5 ~ 2.0

音效名的两种写法插件都会自动转换，按你的服务端版本适配：

yaml 
# 写法一：枚举名（原版 1.9+ 风格）
Sound: "ENTITY_CAT_AMBIENT,1,1"

# 写法二：资源路径（原版 1.13+ 风格）
Sound: "entity.cat.ambient,1,1"

# 带命名空间也可以
Sound: "minecraft:entity.cat.ambient,1,1"

标题 · Title

格式：标题,副标题,淡入,停留,淡出，三个时长单位是 tick（20 tick = 1 秒），省略时默认 10/40/10。

yaml 
# 完整写法（1.11+ 生效）
Title: "&6%sender%,&b好像在艾特你,10,30,10"

# 只想要标题和副标题（任何版本都可用）
Title: "&6%sender%,&b好像在艾特你"
1.8 ~ 1.10 的标题
这些版本的服务端只有两参 sendTitle，后三个时长参数会被忽略、使用服务端默认值。 想让配置在所有版本行为一致，就只写前两段。

跨版本说明

插件对标题和音效分别做了适配，运行时探测当前服务端支持哪个 API，再选用对应实现。 整个过程不使用 NMS 反射（不碰服务端内部类），所以对各类分支服、混合端更友好。

服务端版本标题音效名
1.8 ~ 1.10 两参实现，忽略淡入/停留/淡出 Sound 枚举（1.8 的枚举名较短，如 CAT_AMBIENT）
1.11 ~ 1.12 五参实现，支持自定义动画时长 枚举名格式
1.13 ~ 26.x 五参实现 资源路径格式
音效解析失败不会影响其他功能
如果音效名在当前版本确实不存在，插件只会在控制台打一条警告， 聊天提示与标题照常发送，命令也不会因此报错。

PlaceholderAPI

PlaceholderAPI 是可选软依赖：装了它会自动注册本插件的占位符，没装也完全不影响运行。

本插件提供的占位符

占位符含义
%tuolingat_online%当前在线玩家数
%tuolingat_player%当前玩家名
%tuolingat_cooldown%该玩家剩余的艾特冷却秒数（0 表示可用）

可以放在计分板、聊天格式或其他支持 PAPI 的地方，例如：

text 
冷却: %tuolingat_cooldown%s
在线: %tuolingat_online%
两个已知限制
  • 插件文案里只解析自带的 %target% / %sender% / %cooldown%， 其他插件提供的 PAPI 占位符不会在插件文案中被解析。
  • 执行 /papi reload 后，本插件的占位符可能需要重载插件才会重新注册。

常见问题

玩家打 @名字 没反应，也没提示

  • 确认 Setting.EnableChatAt 是 true，改完要 /at reload 或重启。
  • 确认对方在线：名字不存在或已离线时会提示"玩家不存在或者不在线"，不会有其他动作。
  • 如果连"不存在"的提示都没有，说明聊天监听没生效（回到第一条）。

冷却中对方还是收到了？

冷却只在触发前拦一次。请确认走的是哪条入口：@all/@全体玩家/@random/@随机玩家 按设计不受冷却限制。

OP 一直没冷却，想限制怎么办

把 Setting.OpNoCooldown 改成 false，OP 就和其他玩家一样受 CommandCooldown 限制。

1.8 服务端没有声音，控制台有警告

1.8 的音效枚举名与其他版本不同（例如 1.9+ 的 ENTITY_CAT_AMBIENT 在 1.8 叫 CAT_AMBIENT）。 插件会自动转换大小写与分隔符，但无法把"改过名"的音效自动映射成 1.8 的老名字。 请在配置里填写1.8 实际存在的枚举名。

标题的动画时长没生效

1.8 ~ 1.10 的服务端不支持设置动画时长，属于服务端限制。1.11+ 五参写法才会生效。

改了配置没变化

执行 /at reload（需要 tuolingat.reload 权限）。如果是替换了 jar，请整服重启，不要依赖热重载。

为什么命令有 /at 和 /hanat 两个

两个是同一个功能的别名，方便与其它插件的命令名错开。任选其一即可。
